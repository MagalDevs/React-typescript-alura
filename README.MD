# Gerencie aplicações React com Typescript - Alura

Este repositório contém os códigos desenvolvidos durante a formação *Gerencie aplicações React com Typescript* da Alura. Cada curso da formação está organizado em uma branch separada para facilitar o acesso e a navegação.

## 📂 Estrutura do Repositório

Cada curso da formação tem uma branch específica. Para acessar o código de um curso específico, basta clicar no link correspondente.

### 📌 Cursos disponíveis:

1. *[React: escrevendo com Typescript](https://github.com/MagalDevs/React-typescript-alura/tree/React-Escrevendo-com-Typescript)*


## 🚀 Como utilizar este repositório?

1. Clone o repositório:
   bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   

2. Acesse o repositório:
   bash
   cd seu-repositorio
   

3. Troque para a branch desejada:
   bash
   git checkout nome-da-branch
   

4. Instale as dependências:
   bash
   npm install
   

5. Inicie o projeto:
   bash
   npm start
